# STUDENT-SOCIAL-MEDIA-USAGE-ANALYSIS
This Tableau project analyzes student social media usage and its impact on academic performance, sleep, and mental health using 1,705 records. It features 5 interactive charts, 3 KPI cards, and 4 slicers to explore usage patterns across platforms and countries, identify trends, and gain meaningful insights into student behaviour.

📌 Project Overview

This project focuses on analyzing student social media usage and its relationship with academic performance, sleep duration, and mental health using Tableau.

The dashboard provides interactive visualizations to explore social media usage patterns across different platforms and countries and understand their potential impact on students.

📂 Dataset Information

* Dataset Name: Student Social Media Usage
* Total Records: 1,705 Rows
* Total Columns: 11
* Visualization Tool: Tableau

🎯 Project Objectives

* Analyze students’ daily social media usage.
* Understand the relationship between social media usage and academic performance.
* Explore the impact of social media on sleep duration.
* Examine the relationship between usage hours and mental health.
* Compare social media usage across different platforms and countries.

📈 Dashboard Features

KPI Cards

The dashboard includes 3 key performance indicators:

* Average Daily Usage Hours: 5 Hours
* Average Mental Health Score: 6.2
* Average Sleep Duration: 7 Hours

📊 Visualizations

The dashboard contains 5 interactive charts:

1. Usage and Sleep by Platform – Dual-Axis Bar Chart
2. Academic Impact by Platform – Heat Map
3. Usage Hours vs. Academic Impact – Horizontal Bar Chart
4. Countries by Mental Health and Usage – Pie Chart
5. Usage vs. Mental Health – Scatter Plot with Trend Line

🎛️ Interactive Filters (Slicers)

* Gender
* Country
* Overall Impact
* Age

💡 Key Outcomes

This project demonstrates how Tableau can transform raw data into meaningful visual insights. The interactive dashboard helps users explore student social media habits and understand their possible relationships with academic performance, sleep, and mental health.
